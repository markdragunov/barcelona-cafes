RAG search

          

            Location-aware hybrid search: if the query mentions a street,
            landmark, or neighborhood, cafes are first filtered to a 1 km
            radius (Google Geocoding + local coordinates), then ranked with
            ChromaDB + BM25. Answers use only local cafe data.
